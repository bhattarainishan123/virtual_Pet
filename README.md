# Hangry Pets
Team project for CS 122_Fall 2026
A virtual pet web app called Hangry pets built with Python, Flask, SQLite.
Adopt the pet keep it fed, happy and rested and watch it level up.

## Setup : 

Clone the repo and go into the repo : 
In Terminal do this :
git clone https://github.com/bhattarainishan123/virtual_Pet
cd virtual_Pet
________________________________________________________________________________________

Create the virtual environment inside virtual_Pet: 
on Mac : 
python3.13 -m venv venv
on window :
py -3.13 -m venv venv
________________________________________________________________________________________

Activate the virtual environment :
on Mac:
source venv/bin/activate
on window: 
venv\Scripts\activate
________________________________________________________________________________________

Install all the required libraries : 
pip install flask flask-login pandas matplotlib pytest
